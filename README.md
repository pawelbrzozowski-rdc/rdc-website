# RDC-Analitics Website

Statyczna strona RDC-Analitics przygotowana pod obecny hosting.

## Główne pliki

- `index.html` - strona główna z lokalnym SEO i prostym przekazem.
- `assets/site-data.js` - centralne źródło treści, danych firmowych, demówek i SEO.
- `assets/app.js` - renderowanie nawigacji, kart branż, podstron demówek i metatagów.
- `assets/styles.css` - wspólny styl strony.
- `realizacje/index.html` - lista przykładów branżowych.
- `realizacje/*/index.html` - podstrony SEO dla 8 typów firm.
- `robots.txt` i `sitemap.xml` - podstawowe pliki SEO.

## Założenie komunikacji

Strona sprzedaje najpierw `Inwentaryzację danych i analizę procesu`.
Dashboard jest pokazany jako efekt uporządkowania danych, a nie jako pierwszy produkt.
